# guide-finance
Tu travailles. Tu gagnes de l'argent. Et pourtant tu dois encore. Il est temps que ça change. La dette te réveille la nuit. Elle te fait honte. Ce guide te donne les outils concrets pour t'en sortir — la psychologie, les méthodes, le budget, les scripts de négociation, le plan 90 jours, et les conversations difficiles sur l'argent.
